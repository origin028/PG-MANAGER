SMART GROUP PG MANAGEMENT SYSTEM — PRODUCTION DEPLOYMENT SPECIFICATIONS
================================================================================
Date: 2026-11-21

Git Branch: main (origin: https://github.com/origin028/PG-MANAGER.git)

1. ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------
- Unified Backend API: FastAPI (Python 3.12, Uvicorn, SQLAlchemy 2.0, Psycopg 3)
- Relational Database: PostgreSQL with Alembic Migrations (Head: b8c9d0e1f2a3)
- Admin Portal: Flutter Web (Deployed to Vercel with SPA routing)
- Admin Mobile App: Flutter Android Release APK (com.originpg.admin)
- Resident Mobile App: Flutter Android Release APK (com.originpg.resident)

2. COMPONENT DEPLOYMENT TARGETS & COMMANDS
--------------------------------------------------------------------------------
[A] FASTAPI BACKEND & POSTGRESQL (Render / Cloud Container)
    - Source: pg-management-system/backend
    - Entry Point: app.main:app
    - Build Command: pip install --upgrade pip && pip install -r requirements.txt && alembic upgrade head
    - Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT --workers 4 --proxy-headers --forwarded-allow-ips=*
    - Health Checks:
        * GET /api/v1/health (Comprehensive DB + app status)
        * GET /api/v1/health/live (Liveness probe)
        * GET /api/v1/health/ready (Database pool readiness probe)
    - Blueprint Configuration: render.yaml & Procfile

[B] ADMIN WEB APPLICATION (Vercel)
    - Source: pg-management-system/admin_app
    - Build Command: flutter build web --release --dart-define=API_BASE_URL=<PRODUCTION_API_URL>/api/v1
    - Output Directory: build/web
    - SPA Rewrite: vercel.json (rewrites all paths to /index.html)
    - Caching: Immutable 1-year cache on static hashing bundles, no-cache on index.html

[C] ANDROID RELEASE APKS
    - Admin APK: release/admin-app.apk
        * Package ID: com.originpg.admin
        * Version: 1.0.0 (1)
        * Permissions: INTERNET, ACCESS_NETWORK_STATE
    - Resident APK: release/resident-app.apk
        * Package ID: com.originpg.resident
        * Version: 1.0.0 (1)
        * Permissions: INTERNET, ACCESS_NETWORK_STATE, READ_EXTERNAL_STORAGE
        * Features: Direct UPI Intents (GPay, PhonePe, Paytm, BHIM)
